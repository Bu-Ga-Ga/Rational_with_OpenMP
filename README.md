# Программа для работы с рациональными числами с параллельными вычислениями

## Описание программы

Программа реализует систему для работы с массивами рациональных чисел (дробей) с поддержкой параллельных вычислений с использованием OpenMP. Основные возможности включают арифметические операции, сокращение дробей и ввод/вывод данных.

## Основные особенности

1. **Параллельные вычисления**:
   - Использование OpenMP для ускорения операций
   - Специальные операторы (`&`, `/`, `%`) для параллельных версий операций
   - Метод `reduction1()` с параллельным сокращением дробей

2. **Архитектура**:
   - Фабричный метод для создания объектов
   - Виртуальные функции для полиморфного вывода
   - Два формата вывода дробей (CRat1 и CRat2) (в строку и в столбец)


## Классы и структуры

### Основные классы
- `CRat` - базовый класс для работы с рациональными числами
  - `numerator` - вектор числителей
  - `denominator` - вектор знаменателей
  - `len` - количество дробей

- `CRat1`, `CRat2` - производные классы с разными форматами вывода

### Фабричные классы
- `CFabricRat` - абстрактная фабрика
- `CFabricRat1`, `CFabricRat2` - конкретные фабрики для создания CRat1 и CRat2

## Основные операции

### Арифметические операции
| Операция | Описание | Параллельная версия |
|----------|----------|---------------------|
| `+` | Сложение массивов | `&` |
| `-` | Вычитание массивов | `/` |
| `*` | Скалярное произведение | `%` |

### Другие методы
- `reduction()` - последовательное сокращение дробей
- `reduction1()` - параллельное сокращение дробей
- `Input()` - чтение данных из файла
- `Output()` - запись результатов в файл
